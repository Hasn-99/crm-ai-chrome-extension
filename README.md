# CRM AI Chrome Extension

AI-powered Chrome extension designed to streamline CRM workflows directly inside CDK without relying on external tools or platforms.

---

## 🚀 Overview

This tool eliminates the need to switch between multiple systems by bringing AI-powered analysis, updates, and follow-ups directly inside the CRM.

The goal is simple:  
👉 Handle an entire lead — analyze, update, and follow up — in under one minute.

---

## 🔥 Key Benefits

- ⚡ **Save Time**  
  Automates follow-ups and note generation using AI, reducing time spent on each lead.

- 🔒 **Stay Inside the CRM**  
  No third-party tools or external platforms — everything happens within CDK.

- 🧠 **AI-Powered Workflow**  
  Generate texts, emails, and notes based on real customer history and behavior.

- 📊 **Unified Customer Memory**  
  Tracks interactions, status, behavior, and recommendations in one place.

- 🔄 **Real-Time Updates**  
  Log interactions (visit, call, email, SMS) and instantly update customer status and analysis.

- 🎯 **Faster Decision Making**  
  AI provides next-step recommendations and follow-up strategies automatically.

---

## 🧩 How It Works

1. Open any CRM tab  
2. Click the floating action button (circle)  
3. A popup opens and automatically extracts customer data  
4. Use:
   - **Quick Update** → log interaction & update status  
   - **AI Writer** → generate texts, emails, or notes  
   - **Analyzer** → get next-step recommendations  

👉 All within seconds — no switching tabs or manual work.

---

## 🧠 Interface Breakdown

- **Top Section**  
  Displays detected customer data and unified memory (history, status, insights).

- **Quick Update Menu**  
  Log interactions (in-person visit, phone call, email, SMS) to update customer status and feed analysis.

- **AI Writer**  
  Command-based tool to generate follow-ups, messages, and internal notes.

- **Analyzer**  
  Provides customer insights, behavior patterns, risks, and next-step actions.
