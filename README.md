# CRM AI Chrome Extension

AI-powered Chrome extension that enhances CRM workflow by extracting customer data and generating AI-based notes and follow-ups.

## Features
- Auto-detect customer data from CRM
- AI-generated notes, emails, and texts
- Customer memory tracking and timeline
- Real-time workflow assistant
